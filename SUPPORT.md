# Support

pydoccraft is maintained on a best-effort basis without a response-time or compatibility SLA.

- Use [GitHub Discussions](https://github.com/narain1/pydoccraft/discussions) for usage questions and design conversations.
- Use [GitHub Issues](https://github.com/narain1/pydoccraft/issues) for reproducible bugs and focused feature requests.
- Use the private process in [SECURITY.md](SECURITY.md) for suspected vulnerabilities.

Before requesting help, check the [API documentation](docs/api.md), [format limitations](docs/formats.md), and [safety behavior](docs/safety.md). Include the package version, Python version, operating system, source format, operation, complete error message, and a minimal safe reproducer.

Do not upload confidential, personal, proprietary, or potentially malicious documents to public issues. Prefer generated synthetic samples.

Only the latest release is actively supported. Compatibility and fidelity limitations documented for the pinned upstream engines are not necessarily defects.
