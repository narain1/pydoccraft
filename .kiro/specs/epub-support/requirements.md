# EPUB requirements

## Extraction

1. Detect EPUB 2 and 3 containers and read them in-process. Preserve spine order, repeated entries, and non-linear entries. Expose one compatibility page per entry.
2. Preserve ordered Dublin Core values, OPF meta refinements, manifest records, and hierarchical EPUB 3 navigation or EPUB 2 NCX. Resolve UTF-8 resource paths using archive separators on every host.
3. Preserve semantic headings, paragraphs, preformatted text, inline link labels and character offsets, nested tables, captions, spans, row groups and headers. Preserve referenced raster or validated static SVG images, their alternative text and link metadata, and MathML text and source markup.
4. Return owned extraction values. Support bounded byte retrieval for a particular archive resource while the document is open.
5. Resolve EPUB 3 media-overlay associations, sequence order, roles, text anchors and local audio clip boundaries. Expose a chapter's ordered cues and bounded reads of the corresponding audio bytes.

## Safety and errors

1. Preflight member counts, paths, archive structure, lengths, expansion, compression ratios, and local/central consistency. Limit individual and cumulative reads, XML sizes and structure, and normalized output.
2. Parse UTF-8 XML without custom DTDs. Reject unsupported package selection, archive traversal, remote resource loading, and encrypted content. Never execute active content.
3. Report malformed source and unsupported operations through stable errors. Reject authoring mutations atomically when they would violate limits or input validation.

## Creation and editing

1. Create reflowable EPUB 3 with title, identifier, language, ordered authors and chapters, and optional publication date. Support headings, paragraphs, lists, tables, preformatted text, inert links, common raster images, and validated static SVG.
2. Use the existing editable-document bytes, path/stream save, copy, context manager, and close lifecycle. Reopen created bytes through the extraction path.
3. Limit individual images to 16 MiB, cumulative media and chapter content to 64 MiB each, and encoded EPUB output to 128 MiB.
4. Update selected Dublin Core title and description fields in an existing unsigned book. Preserve the uncompressed bytes of untouched chapter and resource members and the unrelated OPF fields. Reject signed and DRM-protected books.
5. Replace multiple XHTML and SVG chapter resources by spine position in one transaction. Preserve the resource media types and validate the viewport of every replaced fixed-layout document. Preserve the original publication's navigation and spine and the manifest fields unrelated to the replacement. Update EPUB 3 `mathml` and `svg` resource properties for the replacement content. Keep existing IDs targeted by hyperlinks in the staged XHTML and SVG, package guide, EPUB navigation, and media overlays. Resolve targets in retained content documents outside the spine and compatibility NCX. Allow one batch to rename IDs and update their chapter links together. Reject edits that fail validation and leave the original usable.
6. Add, remove and reorder spine entries in one transaction. Update EPUB 3 navigation and EPUB 2 NCX, preserving unrelated package information and referenced resources. Synchronize both navigation files when the EPUB 3 spine references a compatibility NCX. Declare MathML and inline SVG in newly inserted EPUB 3 XHTML chapters. Accept static SVG with a numeric viewBox as a new EPUB 3 fixed-layout spine entry. Validate new and replaced SVG chapters with the staged archive's stylesheets and images. Add, replace and remove local resources using decoded archive paths. Reject removals that would break retained package, XML or stylesheet references in the final edit. When replacing a packaged SVG, preserve its previously resolved fragment targets in retained and newly staged XML.
7. Author EPUB 3 media overlay associations for existing or newly inserted chapters. Generate SMIL from ordered text targets, local audio clips and nested sequences with chapter fragments and inherited roles. Update package duration metadata and support detaching associations. When a chapter leaves a shared SMIL resource, retain other chapters' cues, timing order and roles, repair sequence targets, and recompute the affected durations. Validate chapter targets and retained overlays when reopening the result.
8. Replace a declared IDPF-obfuscated font from valid plain font bytes. Preserve its obfuscation and package identifier. When staged reference checks permit resource removal, remove the deleted fonts' declarations and omit an empty encryption file.

## Preview and conversion

1. Preview supported reflowable chapters as PNG with the common DPI and clipping API. Export the semantic profile to DOCX and PDF, starting each chapter on a new page.
2. Retain supported native text, tables, raster images and Presentation MathML. Render supported equation structures through the native equation backend and export native DOCX equations. Return an explicit error when a structure cannot be projected safely.
3. Render fixed-layout XHTML at its numeric viewport and static SVG at its viewBox dimensions while honoring package and spine layout declarations. Render requested synthetic spreads with page progression, placement, package and spine spread rules, and clipped output at requested DPI. Support explicit visual PDF export with one image per selected fixed-layout page. Preserve each original viewport as the PDF page size and place image samples on the export DPI grid. Preserve the publication table of contents as a nested PDF outline, remap retained targets to the selected output pages, and use fragment coordinates where available. Preserve actionable local and safe external links on visible XHTML text and images and standalone SVG objects. Apply viewport and layout clipping to the clickable areas, respect reordered and repeated selections, and leave omitted or unsafe targets inert. Offer searchable fixed-layout PDF export from rendered XHTML, MathML and SVG while preserving the raster page appearance, navigation, page selection and links. Exclude CSS-hidden text and text completely outside the viewport or layout clipping bounds. Preserve links in SVG text runs and within inline SVG in XHTML, with explicit local destinations for visible text-span fragments. Honor native nonrectangular clipping and SVG alpha and luminance masks when retaining searchable text and link geometry.
4. Apply the supported author CSS cascade for styled XHTML. Render a clipped region of long styled chapters without emitting outside packaged-font outlines, subject to the bounded layout and outline checks. Honor packaged font Unicode ranges and the declared fallback family order for XHTML and static SVG. Preserve preferred-face glyphs when selecting fallback faces and report when the native SVG shaper cannot retain the requested text. Resolve unregistered custom properties and var() in supported XHTML and SVG declarations after the cascade, including inheritance, fallbacks, cycles, and shorthands. Read inline, embedded, linked and imported styles using archive-relative resolution. Exercise inherited typography, positioning, colors, box styling, and block, flex and grid layout with pixel-level acceptance tests. Bound XHTML box styles, MathML styles and selector work independently. Render tall chapters within bounded paint coordinates and enforce the shared pixel limits on full and clipped output.
5. Shape XHTML text with archive-local CSS font faces in a chapter-scoped collection, including static TrueType, OpenType, WOFF and WOFF2, and IDPF-obfuscated fonts. Apply XHTML font-face Unicode ranges to the packaged font's effective character map. Prefer later matching face declarations for overlapping ranges. Shape XHTML using the ordered inherited font-family stack and advance to the next family for missing glyphs. Apply inherited CSS variable-axis settings and optical sizing in XHTML and forward these properties to the static SVG preview renderer. Match XHTML font-face weight, width and oblique angle ranges with fractional values. Choose width before style and style before weight, preserve distinct inherited and inline angles, and apply the selected angle to the variable font's slant axis. Keep signed fractional angles when an upright XHTML face needs synthetic oblique. Apply descriptor axis defaults per selected face, before optical sizing and element-level settings. Match static SVG font-face weight, width and signed oblique ranges and apply the selected face’s variation defaults to each supported text run. Retain inline image and equation placement and table spans. Render validated static SVG content in XHTML and rasterize it in semantic exports. Support use elements targeting graphics and symbols in the same SVG subtree. Bound recursive reference expansion and reject external, missing, ambiguous or cyclic targets.
6. Render local SVG CSS from prolog stylesheet instructions and embedded styles. Resolve CSS imports, packaged fonts and referenced PNG or JPEG images inside the archive. Exercise the SVG rendition in spine pages, XHTML images and semantic export while preserving the original SVG payload. Support local linear and radial gradient templates and a single Gaussian blur primitive per filter. Reject missing, ambiguous, external and cyclic effect references and bound raster work after applying the render transform.
7. Preserve inherited MathML run size, color and variant, and project supported accents, movable limits, tensor indices, separators and spacing into editable equations. Apply the supported chapter CSS cascade to formula colors, font sizes, bold and italic runs, and movable limits in preview and native export. Retain annotations and indentation in source markup, and normalize XML whitespace when extracting or projecting the primary presentation. Preserve nonbreaking spaces. Render MathML tables with row and column spans in styled and unstyled chapters, including tables nested inside a larger expression or a containing cell. Honor supported size and position attributes on mpadded and vertical mspace dimensions in previews and fixed-layout PDF. Place the measured boxes inside the native layout for surrounding fractions, radicals, and scripts. Export a standalone spanning table with native merged or nested cells and editable equations in DOCX. Preserve positioned, searchable text and vector rules for composed MathML in reflowable PDF, including equations mixed with paragraph text or contained in XHTML table cells. Reject composed equations that cannot fit the export text area. Honor custom stacked fraction rule thickness and numerator and denominator alignment in reflowable and fixed-layout previews and PDF. Keep centered default-rule and barless fractions editable in DOCX. Export fixed, additive and content-relative MathML padding dimensions and vertical math spaces as editable DOCX equations. Preserve supported nonnegative left offsets, nested formula structure, and native cells in standalone spanning tables without adding visible text.
8. Decode local PCM WAVE, MPEG Layer III, AAC-LC MP4, mono, stereo or surround Ogg Opus, and mono or stereo Ogg Vorbis overlay audio to bounded PCM clips with the SMIL interval and target. Apply supported Xing/Info encoder delay and padding to MP3 timing, and honor Ogg Opus pre-skip, final sample position, and output gain independently for each logical stream. Play sequentially chained streams in Opus mapping families 0 and 1 on one 48 kHz sample timeline. Play sequential Ogg Vorbis links with the same sample rate and channel count, preserving their initial and final granule positions. Read and author overlay cues referencing multiplexed Ogg resources. Select an Opus track by zero-based index for each audio resource and apply that index to every sequential segment. Require an explicit selection when any segment has multiple Opus streams. Preserve speaker assignments in the returned WAVE clips and chunks. Provide readable narration for text-only cues, allow playback to start at a chapter cue index, and stream long audio cues in bounded chunks while holding their target active.
9. Read the ordered media sources, video posters, and WebVTT and TTML track references from XHTML. Permit edits that preserve the referenced local resources. Show packaged posters or authored fallback markup in static previews. Stream supported local audio sources in bounded PCM chunks with optional clip bounds and Opus track selection. Stream local progressive 8-bit H.264 video from MP4 as RGB8 frames in composition order with bounded seeking, original pixel aspect ratio, and clipped frame intervals. Use the same presentation clock to stream an available AAC-LC soundtrack. Leave URLs inert and playback under caller control. Decode local WebVTT and media-time TTML as owned, bounded text cues with original timeline positions. Carry cue state across seeking and split video frame intervals on caption boundaries. Apply local normal-play-time URI fragments to audio and video without shifting the presentation clock.
10. Stream archive-local 8-bit Ogg Theora with 4:2:0, 4:2:2 or 4:4:4 chroma as RGB8 with the authored picture window and pixel aspect ratio. Preserve frame intervals during clipped playback and caption transitions. Support sequential Ogg segments with one video track per segment and either video alone or one soundtrack in each segment in a consistent Opus or Vorbis format. Start the next segment after the longer track, with silence in intermediate soundtrack gaps and no synthetic pictures. Honor authored local source order and permit explicit source selection.
11. Stream packaged WebM with a single VP8 or SDR VP9 video track and an optional soundtrack in Opus or mono/stereo Vorbis. Support a single audio-only WebM track in either format. Convert supported 8-, 10- and 12-bit planar YUV pictures to RGB8 with their WebM timestamps, display ratio and crop. Seek through bounded keyframe preroll and preserve temporal fragments and caption intervals. Honor Opus pre-skip and output gain, and apply final discard padding and audio lacing for both audio codecs. Seek Vorbis using the preceding overlap window and place the decoded samples on the original presentation clock. Handle rounded modern start timestamps and consistent legacy end timestamps. Respect start-timed discontinuities with silence in a gap and earlier samples retained across an overlap. Bound EBML element count, nesting, packet size and total packets before native decoding.
12. Full source CSS and fixed-layout fidelity, richer MathML layout, broader embedded video coverage, styled timed text, additional media fragment dimensions and remaining overlay codecs and playback controls remain open. DRM, script execution and unlisted conversion pairs remain outside the scope.
