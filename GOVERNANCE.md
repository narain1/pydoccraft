# Governance

pydoccraft is currently maintained by repository owner `@narain1`, who has final responsibility for project direction, releases, security coordination, and enforcement of repository policies.

Decisions are made in the open through issues, discussions, and pull requests whenever security or privacy does not require confidentiality. Technical decisions prioritize the documented public API, safe handling of untrusted input, upstream-backed format behavior, permissive licensing, and a compact offline runtime.

Regular contributors may be invited to triage issues or review changes based on sustained, constructive participation. Commit or release access is granted explicitly and may be removed when inactive or when needed to protect the project.

Changes to governance, licensing, supported formats, or compatibility guarantees should be proposed publicly and documented before implementation. Security embargoes are the exception and follow [SECURITY.md](SECURITY.md).
